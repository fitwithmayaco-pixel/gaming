# gaming

## 🌴 Grand Theft Auto VI - Official Digital Store & Admin Dashboard

A realistic, animated GTA 6 (Leonida / Vice City) themed digital store and admin panel for selling walkthrough e-books, 4K YouTube thumbnails, neon sticker packs, and creator bundles with instant access.

### Features
- **Cinematic Hero**: Looping HD background video, vibrant Vice City sunset gradients, scanlines.
- **Interactive 3D E-Book**: Hardcover 3D book mockup with real-time mouse parallax tilt and light gloss sheen.
- **Universal Checkout**: Direct access redirect on product cards and modals.
- **Admin Panel (`/admin`)**: Upload new digital assets, manage prices, thumbnails, descriptions, and view metrics.
- **Supabase Integration**: Auth, database, storage bucket, and role-based access control (`admin` vs `user`).
- **Vice City FM**: Built-in retro synthwave radio player.

### Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Supabase JS
- Lucide React & Framer Motion
